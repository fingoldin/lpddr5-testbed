## Conventions of the coordinate files

- **Origin**: the drill / place origin of the board = the lower-left corner of the card rectangle seen from the front (the finger-1 end of the
  finger edge). **x to the right, y up, millimetres** in the Gerber, Excellon and placement files; the IPC-D-356 file uses 0.0001 inch, same origin.
  The profile therefore spans x 0 .. 69.6, y 0 .. 30.0.
- **Gerber**: X2 attributes, format 4.6, aperture macros enabled, one file per layer, KiCad file names (`.gbr`); the mask files are negative
  (drawn = opening); the legend files have the mask openings subtracted.
- **Excellon**: metric, decimal coordinates, plated and non-plated holes in separate files, finished hole sizes.
- **Placement files** (`Ref, Val, Package, PosX, PosY, Rot, Side`): PosX / PosY are the footprint origin (the centre of the part) in the frame above.
  **The bottom face is NOT mirrored**: x is as seen from the front, through the card. **Rot** is the KiCad footprint orientation: degrees
  counter-clockwise **seen from the front (top) of the card for both faces**; at Rot = 0 a top-side part has its library orientation (pin 1 as in the
  KiCad footprint), and a bottom-side part is the library footprint mirrored top-to-bottom (KiCad's flip). Seen from the back, a bottom-side part is
  therefore rotated by (180 - Rot) degrees counter-clockwise from its library orientation. `check_fab.py` recomputes every numbered pad of every part
  from the row and this convention and compares it with the board.
