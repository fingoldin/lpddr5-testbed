- Write: spread +/-26.7 ps, latest total 801.51 ps; WCK arrives -17.0 ps after the latest DQ before the table is applied
  (negative = before) and is not matched to DQ (tWCK2DQI is trained).
- Read: spread +/-56.8 ps about 892.83 ps; with the table every DQ reaches the capture flop 26.56 ps after the strobe edge that
  left the DRAM with it. Pass the strobe through an IDELAYE3 at value 0 too, so that the insertion delay of the primitive cancels.
- RDQS: In3 from the balls B3 / C4 to a via pair just above fingers 219 / 221 (y = 8.50 mm), then 5.80 mm of F.Cu into the fingers: the same form as a read DQ line. It arrives +30.29 ps from the centre of the read group (-26.56 ps from the latest bit, +87.13 ps from the
  earliest); strobe minus each bit before the table: DQ0 +26.2, DQ1 +10.8, DQ2 +61.8, DQ3 +42.5, DQ4 -26.6, DQ5 -23.1, DQ6 +78.7, DQ7 +87.1 ps.
- IDELAYE3: range 0 .. 1100 ps, 512 taps of 2.1 .. 12.0 ps.
- The command bus needs no table: its ten nets are matched on the card; what the +/-5 ps knowledge of the host leaves is
  removed per bit with the output delay of the command pins.

## What follows from the pin names

- command: bank 65, 11 pins in 2 nibble(s): T0L, T0U
- write: bank 64, 10 pins in 5 nibble(s): T1L, T1U, T2L, T2U, T3U
- read: bank 66, 18 pins in 6 nibble(s): T1L, T1U, T2L, T2U, T3L, T3U
- reset: bank 66, 1 pins in 1 nibble(s): T0L
- ck_p / ck_n on AM21 / AN21 (IO_L4P_T0U_N6_DBC_AD7P_SMBALERT_65, bitslice 0 of T0U): clock-capable: DBC
- wck_p / wck_n on AF18 / AG18 (IO_L14P_T2L_N2_GC_64, bitslice 2 of T2L): clock-capable: GC; pair inverted on the host
- rdqs_p / rdqs_n on AK8 / AL8 (IO_L10P_T1U_N6_QBC_AD4P_66, bitslice 0 of T1U): clock-capable: QBC; pair inverted on the host
- ck_p (AM21, IO_L4P_T0U_N6_DBC_AD7P_SMBALERT_65) has the multi-function name SMBALERT: UG1075 table 1-4 warns that such a pin can be driven before configuration (it names Kintex / Virtex UltraScale+; whether that holds for this Zynq part is not stated). On this card it could only move one divider node between 0 V and its high level while the DRAM is held in reset
- outputs in the read bank: reset_n (AP11, LVCMOS12)
- read data on global-clock (GC) pins: rdq_p[0] (AH11), rdq_p[4] (AJ9)
